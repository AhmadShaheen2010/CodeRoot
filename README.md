# 🌱 Code Root - Grow Your Coding Habits

**Code Root** is a VS Code extension that visualizes your code quality and typing habits as a living plant. Write clean code, and your plant will thrive. Let your linter warnings pile up, and you'll see your plant wilt. Your top keystrokes are tracked too, giving you insights into your habits.

---

## ✨ Features

- 🪴 **Visual Plant Feedback**  
  Your linter score is translated into the health of a digital plant. More issues = a sad plant. Cleaner code = a thriving one.

- 🧠 **Habit Tracker**  
  Tracks your top 10 most pressed keys to give insight into your typing patterns (stored locally in a JSON file).

- 🎯 **Gamified Code Quality**  
  Motivates cleaner code through visuals and interaction.

- 📦 **Lightweight & Local**  
  All keypress tracking is done locally. Nothing is sent externally.

## 📁 Data Storage

- Keypress data is stored in a local `.json` file (e.g. `~/.keyPressData.json`).
- No internet access or cloud syncing. Your data stays on your machine.

---

## 🔧 Requirements

- A working linter setup (e.g. ESLint for JavaScript/TypeScript).
